# DreamLayer Asset Workflow

1. Generate one focused reference.
2. Review identity, silhouette, camera angle, and readability.
3. Create behavior states from the approved reference.
4. Remove backgrounds only from accepted images.
5. Resize final transparent PNGs for browser use.
6. Import them from `public/assets/images`.
7. Record every operation and result in `asset-plan.json`.

The DreamLayer API key is private and must never be included in the browser build.
